會議助手設定

設定與金鑰都存在這台電腦，不會上傳。需要你填的只有金鑰、名字、背景筆記 —— 其餘（模型、辨識引擎、摘要頻率）都已經設成實測最好的組合，而且全部免費。

API 金鑰

三家都是免費方案：不需要信用卡，用超過就是被拒絕，不會變成帳單。 金鑰只存在這台電腦的瀏覽器裡，不會進入 GitHub（這個專案是公開的， 所以金鑰絕對不放在程式碼裡）。換一台電腦要重貼一次。

兩個 NVIDIA 帳號會輪流使用，把「單一帳號撞到上限」的機率往後推。 只填一個也可以。

只有在問題明顯需要「會議之外的最新資訊」時才會查（例如提到法規、匯率、最新消息）。 一般的會議問題靠逐字稿回答，不會浪費查詢額度。

你是誰

這欄一定要填。別人在會議裡講到這些名字時，才會自動幫你準備回答建議。 沒填的話「問答」分頁只能手動提問。多寫幾種叫法（全名、綽號、英文名）比較不會漏。

寫得越具體，回答建議越能直接照唸。不要放密碼或金鑰。

摘要更新頻率

兩個條件都成立才會更新摘要。秒數是最短間隔，也就是真正的節流上限： 設 300 就是「最多每 5 分鐘一次」，即使中間累積了 50 段也會等到時間到。 段數則是「至少要有這麼多新內容才值得跑一次」，避免冷場時為兩句話白跑。
預設 8 段 / 300 秒。摘要走 Groq 的免費方案（每天有 token 上限）， 秒數設太小會在一場會議裡就把當天額度用掉，建議不要低於 180。 額度用完會自動退回 Claude Code（慢很多，但側邊欄會告訴你）。

本機語音辨識

這是備援。預設的逐字稿走 Groq 的雲端辨識（快 8 倍、中文準確得多）， 只有在沒填 Groq 金鑰時才會用到這條本機路線 —— 它用的是本機 whisper.cpp（small 模型）， 零費用、資料不離開這台電腦，代價是慢且準確度較低。 需要跑過一次 tools\install-whisper.ps1。 辨識伺服器會在開始聆聽時自動啟動、停止時自動關掉，常駐約 400 MB 記憶體， 上面那顆「停止」只是想提早把記憶體要回來時用的。
