會議助手設定

設定會存在這台電腦的擴充功能儲存區（chrome.storage.local），不會上傳到任何伺服器。

模型後端

Claude Code透過本機橋接呼叫你已登入的 Claude Code，用的是 Claude Pro 訂閱額度，不會按量計費。 需先執行一次 bridge\install.ps1 註冊橋接。缺點是每次呼叫要 10–30 秒（每次都重新啟動 CLI）， 所以摘要很適合、即時回答不適合 —— 這就是上面那個勾選項的用途：摘要走 Claude Code，即時回答走本機模型，兩者都免費。
Chrome 內建模型是 Gemini Nano，跑在你電腦上：零費用、資料不外流、1–3 秒，但 context 小、看不懂畫面、中文品質最弱。 首次使用需在側邊欄按「⚡ 啟用免費模型」下載一次模型。
注意：Claude Pro／Max 訂閱不含 API 額度。上面的「Claude API」選項是另外按量計費的， 不會動用你的訂閱；反之「Claude Code」動用訂閱，不會產生 API 費用。

Claude API（選用）

在 platform.claude.com 建立。 金鑰存在瀏覽器本機，摘要與問答會直接從擴充功能呼叫 Claude API。 若要多人共用，建議改成由自己的後端代理呼叫，不要散發金鑰。

即時回答

附上畫面才看得懂共享的圖表、簡報或程式碼。走 Claude Code 時是把截圖存成 PNG、讓它用 Read 工具讀檔， 所以不會產生 API 費用，但多一次工具往返：實測純文字 4.6 秒、附圖 10–17 秒，而且多耗 Pro 額度。 Chrome 內建模型看不懂圖片，勾了也沒用（會在答案卡片上說明）。這只是預設值，每次提問都能在側邊欄單獨勾選。

不會無條件開啟：平台字幕本來就包含你自己的發言（還帶真實姓名），兩邊都收會讓同一句話在逐字稿裡出現兩次。 所以只在狀態燈是黃色（找到會議但沒字幕）時自動開，字幕一恢復就自動關。 首次需要按一次「🎤 我的麥克風」授權麥克風，之後才能自動啟動。

寫得越具體，回答建議越能直接使用。不要放密碼或金鑰。

摘要頻率

兩個條件都要成立才會自動摘要。秒數是最短間隔，也就是真正的節流上限：設 300 就是「最多每 5 分鐘一次」， 即使中間累積了 50 段也會等到時間到。段數則是「至少要有這麼多新內容才值得花一次額度」，避免冷場時為兩句話跑一次模型。 想立刻要一份就按側邊欄的 ↻ 摘要 —— 手動觸發不受這兩個限制。
走 Claude Code 的話請把秒數設大一些（建議 300 以上）：它每次呼叫都是一個完整的 CLI session，一分鐘一次會很快撞到 Pro 的用量上限。
摘要是累積式更新：每次只把「新增的逐字稿」送給模型，不重送整場，成本大致與會議長度成線性而非平方。

自架的 Jitsi Meet（選填）

公開站 meet.jit.si 與 8x8.vc 不需要設定，安裝好就能用。 這裡只給自架站：Jitsi 可以自己架，網域無法事先列舉，所以要你授權後再動態註冊內容腳本。 填好網域按上面那顆按鈕，Chrome 會跳出權限確認 —— 必須從這個頁面按，因為權限請求需要使用者手勢。
注意 Jitsi 的字幕靠部署端的 Jigasi 轉錄服務。自架站若沒安裝 Jigasi，會議裡根本沒有字幕可抓， 這時只能用「🎤 我的麥克風」記錄你自己的發言。

聽會議聲音（沒有字幕時用）

Meet 和 Teams 有內建字幕，用不到這個。它是為沒有字幕的會議準備的 —— 例如沒安裝 Jigasi 轉錄服務的自架 Jitsi，或公開的 meet.jit.si（實測 transcription.enabled: false）。
本機原生 whisper.cpp 需要跑一次 tools\install-whisper.ps1 （下載約 260 MB 到 %LOCALAPPDATA%\MeetingAssistant\whisper）。 它跑成一台只綁 127.0.0.1 的小伺服器，由 bridge 在需要時啟動、停止擷取時關掉， 零費用、資料完全不離開你的電腦。 實測 RTF：small 模型 12 秒一段是 0.47、base 是 0.17。 用 small 是因為中文差距很大 —— 同一段音訊 base 把「這季／結帳／對帳／小陳」全聽錯，small 全對， 而原生 small 的速度還比瀏覽器內建的 base 更快。
瀏覽器內建 WASM 的模型在 vendor/（約 99 MB），不必安裝任何東西， 但只有 base 模型、RTF 約 0.5，做成 20 秒一段。原生引擎啟動失敗時會自動退到這條，並在側邊欄說明。
開會時 CPU 被視訊佔用可能讓辨識跟不上。跟不上時會略過片段、在側邊欄明確告知， 並自動把分段拉長（每次辨識有固定成本，段落越長每秒成本越低）—— 而不是安靜地爛掉。
三個引擎都拿不到真實姓名：本機引擎標成「其他人（本機辨識）」，Deepgram 標成「講者 1／2」。 真實姓名只有平台字幕才有，所以有字幕時一律優先用字幕。 自動啟動只在本機引擎下生效 —— 自動花錢是不能接受的。
繁體轉換是在辨識完之後用字表（OpenCC 資料）做的，不是靠提示詞。 實測用繁體 initial prompt 引導雖然讓輸出變繁體，卻會把「對帳」聽成「對戰／對象」—— 換到腳本對、內容錯，不划算。
